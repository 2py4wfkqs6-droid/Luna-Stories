# Luna Stories

Первый экран мини-приложения: иллюстрированный фон и интерактивное нижнее меню.

## Разделы меню

- Истории
- Гардероб
- Награды
- Коллекции
- Профиль

Навигационные иллюстрации и рамка активного пункта находятся в `assets/`. Начальное выделение стоит на вкладке «Награды» как в референсе.
